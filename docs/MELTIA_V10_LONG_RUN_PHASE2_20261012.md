# Meltia v1.0 — フェーズ2：長い連続日英入力の境界候補（2026-10-12）

> **研究用・Draft PR [#12](https://github.com/Fugu0141/Meltia/pull/12)**。
> v1.0-devの追加実験であり、IME・TSFに未接続、正式リリース不可。
> GitHub Actions無料枠枯渇については再確認せず、ローカル検証用のコードを整備する。

## 問題とねらい

`MeltiaUnknownLatinCandidates`は従来、英字連続区間が
**96文字を超える場合に区間全体の未知英語候補を生成せずに捨てる**。
Coreの入力上限は1024 UTF-16単位なので、これまでの候補検出で
長文の英語混在を取り逃がし得た。これは実際の長文での
原因分析を経た精度値ではなく、**コード上で再現可能なカバレッジ欠落**。

フェーズ2は`ExperimentalLongRunWindowing`（既定OFF）を追加し、
**未知英語を確定せず、候補生成の空白だけを縮める**研究を行う。

## アルゴリズムの変更

- 従来の96文字以下の英字連続区間は生成ロジック・得点・候補を変更しない。
- **97文字以上**の英字連続区間について、元の連続区間全体が
  `MeltiaRomaji.CanRead`で読み取り可能なら**そのままスキップ**する。
  長い純粋な日本語ローマ字を未知英語として誤解釈させない。
- 日本語と非日本語の混在があり得る連続区間だけ、
  幅96・歩幅72（重複24）の窓で従来の候補生成を繰り返す。
  候補の最大長24なので、各文字領域が少なくとも一度は
  全体を含む窓に現れる**範囲上の保証**がある。
  ただし実際の候補が得られるかは日本語音韻の可読性・綴り条件に依存し、
  **真の英語境界が必ず候補になる保証ではない**。
- 窓内の仮説は元入力のUTF-16オフセットへ戻す。
  同一spanが重複する場合は、窓の走査順ではなく**最も高い候補得点を採用**し、
  位置で整列して重複を除去する。これも仮説の得点であり、確信度ではない。
  URL・メール、英語ロック・日本語ロック、候補128・Top-K8、
  `AutoCommitAllowed=false`の契約を維持。
- 新オプションだけを有効化する誤設定は例外とし、必ず未知Latin候補生成を
  あわせて有効化する。

**限界**：窓の始点は自然な単語境界と一致しないことがある。
窓の分割により、日本語として読める前後の長い断片が
英語候補の一部に吸収される可能性がある。
また、候補数上限128による**正解候補の脱落**、
演算・割当増加、誤検出の悪化を排除できない。
既存v1.0を置き換えるデフォルト変更はしない。

## 60件の新しい長文合成コーパス

`tests/Meltia.BoundaryEvaluation/LongRunCorpus.cs`：
各12件×5分類、合計60件。いずれもRaw全体は96文字を超える。

| ID | 主題 |
|---|---|
| L01 | 長い日本語ローマ字の中央に英語1区間 |
| L02 | 英語が先頭、後半に長い日本語 |
| L03 | 英語2区間と助詞を長い日本語で挟む |
| L04 | 日本語ローマ字だけの長い負例 |
| L05 | 絵文字・句読点が長い英字列の間にある |

ゴールドは固定の断片指定から生成された**人為的な合成ラベル**。
人手収集した自然文／学習時未使用の盲検holdoutではない。
英語語彙は既存研究で使ったものも含み、汎化性能は主張しない。

### 評価指標

旧`Meltia-v1.0-*` と 新`Meltia-v1.0-windowed-*`を同じRaw・同じ証拠で比較。
独立・Meltype辞書・Meltypeシャドー・両方の4条件を出す。
既存の項目のTop1完全一致、Top-K、Gold候補再現率、
候補数、候補中Gold比率、日本語負例での誤英語区間数を保持。
96文字以下の連続英字しか持たないケースでは、
**候補リスト・Top1・Top-Kの厳密一致**を機械検査する。

既存47＋530＋290＋56＝923件に60件を追加し、
**研究用合成評価983件**（複数母集団の合計であり製品精度ではない）。

## 実行方法（CI不要）

.NET SDK 10 + Python 3.10+を入れたリポジトリのルートから：

```bash
dotnet run --project tests/Meltia.Core.Tests/Meltia.Core.Tests.csproj -c Release

dotnet run --project tests/Meltia.BoundaryEvaluation/Meltia.BoundaryEvaluation.csproj -c Release -- --output artifacts/meltia-longrun-60.json --suite longrun

python tools/run-meltia-quality.py --tier full
```

最後のfull実行で従来923件に新規60件と性能ベンチを加える。
新たなベンチマークは長い純日本語、長い英語1区間・2区間も含み、
従来のv1.0とwindowed実験のp50/p95/p99、割当量比、
候補数中央値・上限・Truncated発生件数を記録する。
