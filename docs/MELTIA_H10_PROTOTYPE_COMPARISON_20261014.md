### 候補モデルについて

- 日本語: 既存 `MeltiaRomaji.CanRead` による読みを候補化。最長12文字まで各開始点を列挙。未完成ローマ字はrawのままフォールバックする。
- 英語: 辞書に存在するかどうかを必須条件にせず、**全ASCII英字の各開始位置から2〜64文字の英語候補**を生成。両言語の文字bi/tri-gramの尤度差で暫定評価し、日本語が読める英語も候補から削除しない。
- 構造: URLとメールは必須。拡張子・ドットファイル・ハイフン語・英数字の連なりは追加候補とする。ケース固有の `githubya`、`mendokuseena` 等を辞書に**書き込んでいない**。
- 探索: `Japanese`/`English`/`Neutral` の状態別に経路を保持し、言語切り替えコストを適用。Backpointerにより出力の全経路コピーを避ける。候補数上限や経路幅でgoldが落ちうることは、別の失敗段階として計測する。
- 注意: 学習シードは実証済みの自然文コーパスではなく、ソースに明示した**小さな研究語彙**である。パラメータ値は確率校正されていない。これを最適モデル・高精度IMEと呼ばない。

## 完全な比較手順

.NET 10 SDKがあるLinux/Mac/Windows環境のリポジトリルートで以下を実行：

```shell
dotnet run --project tests/Meltia.Core.Tests/Meltia.Core.Tests.csproj -c Release
dotnet run --project tests/Meltia.H10Evaluation/Meltia.H10Evaluation.csproj -c Release -- --output artifacts/h10/h10-comparison.json
```

READMEや研究リポジトリへ移動する必要はなく、**Issueに由来する47件の入力・gold・出典URLを、上記テストプロジェクト内に同梱**している。出力は、すべてのケースについて従来型 `v1.0-flank-independent` と新試作 `H10-dual-channel` の以下を保存する。

- 候補に正しい全英語区間が存在するケース数
- Top-K内に正解の全英語区間の組合せが存在するケース数
- Top1の英語区間完全一致ケース数
- 純日本語ケース中の誤英語区間出現数
- 境界precision/recall由来の境界F1（集計はTP/FP/FNベース）
- 各モデルの候補欠落、探索・日本語経路欠落、順位付け失敗
- 分類（EN-OOV/STRUCT/SEAM/JA-PROTECT/CONTEXT/SCRIPT/AMBIGUOUS）ごとの内訳とケース単位の全失敗結果
- 同一実行環境での参考処理時間 p50/p95/p99。47ケース×5回の小標本、JIT/GC/負荷差を含むため一般化禁止

`Are you susi?` の英語部分は空白で分割したENトークン区間に正規化する。字面が同じ `new`/ `aiueo` の対照意図ケースは**真の意味では文脈なし判定不可能**なので、結果を調べる際は独立した意図ラベルであり性能の公平な独立holdoutではないことに注意。

## 採否判断と改善の優先順位

1. GitHub ActionsでC#ビルドとAPI契約テストを通す。失敗時は同PRで修正。
2. 47件は**診断**として既存v1.0とH10を同条件で比較し、負けた事例を全件残す。候補が無いのか、探索で落ちたのか、順位付けの問題かを見分ける。
3. 完全に未知の語・日本語語彙・混在語を含む**別の人手ゴールドholdout**を準備する。同梱のIssue例に合わせたスコア調整をholdout改善として誤報しない。
4. p95/p99と割り当て、長文1024までの計算量、Backspace連打、URL・かな入力・ホストの入力モード変更を追加評価する。今回の文字モデルは候補列挙時の再計算が多いため、遅延が悪化する可能性がある。
5. どのカテゴリも非退行、ラベル品質・コードレビュー・Windows E2E合格のときのみ正式なMeltia Preview取り込みを別途検討する。

## 残る設計リスク

- 候補の数は入力長と最大辺長に増加し、文字モデルは候補ごとに再計算する。一般のリアルタイムIMEに十分な速度とは限らない。
- 手で選んだ少量の語彙で作った文字モデルには未知語の偏りがある。自然文で校正された事後確率や学習済みモデルではない。
- 旧Coreとはスコアの数値系が異なり、スコア差で「何%の確率で正しい」と説明できない。
- `BoundaryEvidence.EnglishWords` はH10では現段階で学習特徴として用いていない。比較はホスト辞書・Meltype予測**なし**の独立条件に限る。辞書あり・実機は別実験。
- 既存の長文評価（530/290/1067件）は今回の47件の代替ではない。総合精度の相対改善を示すまで、研究フラグを既定ONにしない。
